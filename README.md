# Demo Landing Page — Seblak Gacor

Ini adalah prototipe statis untuk presentasi jasa, bukan situs resmi dan belum disetujui oleh pemilik Seblak Gacor.

## File
- `index.html` — halaman responsif, tanpa framework dan tanpa build step.

## Cara melihat secara lokal
1. Ekstrak ZIP.
2. Buka `index.html` di browser.

## Cara deploy gratis dengan GitHub Pages
1. Buat akun GitHub jika belum punya.
2. Buat repository baru, misalnya `seblak-gacor-demo`.
3. Unggah `index.html` ke root repository.
4. Buka Settings → Pages.
5. Pada Build and deployment, pilih Deploy from a branch.
6. Pilih branch `main` dan folder `/(root)`, lalu Save.
7. Tunggu proses publikasi selesai; buka URL yang diberikan GitHub Pages.

Alternatif: Cloudflare Pages dapat digunakan untuk proyek HTML statis. Ikuti petunjuk terbaru pada dokumentasi resmi penyedia.

## Sebelum demo ditunjukkan
- Pertahankan banner “KONSEP DEMO / BELUM DISETUJUI PEMILIK”.
- Jangan menyebut halaman ini sebagai situs resmi.
- Ilustrasi emoji bukan foto asli produk.
- Jangan menambahkan harga, menu, jam buka, nomor WhatsApp, promo, atau klaim lain sebelum dikonfirmasi.
- Setelah pemilik menyetujui proyek, ganti placeholder dengan materi yang mereka izinkan.
- Pastikan tautan dan tampilan diuji di HP.

## Catatan
Demo ini tidak memakai database, formulir, analytics, atau backend. Tombol Maps mengarah ke tautan Maps yang diberikan sebagai referensi.
